# Packs Kenney (CC0)

Tuiles 16x16 de Kenney (www.kenney.nl), licence CC0 1.0 : libres pour tout
usage, attribution non requise mais appréciée. Récupérés via le miroir
CC0 `Tiddybub/2d-assets`.

- `tiny-town/`    : sol (herbe, terre, pavés), toits, murs, portes, arbres, barrières, caisses.
- `tiny-farm/`    : grange à toit vert, sapins, puits, sacs, tonneaux.
- `tiny-dungeon/` : personnages, monstres, objets, coffres, torches, sols et murs intérieurs.

Chaque `tilemap_packed.png` est une grille de 12 x 11 tuiles de 16 px ;
l'index d'une tuile = colonne + 12 * ligne (voir `scripts/world/Art.cs`).
